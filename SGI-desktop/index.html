Envio 100% automático via servidor local

O SGI se comunica com o servidor.py que roda em background. Ele abre o Chrome, acessa o WhatsApp Web e envia a mensagem — sem nenhuma interação do usuário.

Como iniciar: execute python servidor.py na pasta do SGI. Na primeira vez, escaneie o QR Code do WhatsApp Web. Depois o login fica salvo automaticamente.
