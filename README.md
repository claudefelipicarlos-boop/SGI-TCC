## 📝 Descrição do Projeto
O **SGI** é um sistema de gestão de manutenção industrial voltado para empresas que prestam serviços de manutenção em máquinas e equipamentos.

**Problema que resolve:** grande parte dessas empresas ainda controla ordens de serviço, histórico de atendimentos e carteira de clientes de forma manual (planilhas, papel ou sistemas desatualizados), o que dificulta o acompanhamento, gera retrabalho e causa perda de informações importantes.

**O que o sistema faz:**
- Cadastro de equipamentos e clientes
- Agendamento de manutenções preventivas e corretivas
- Envio de alertas automáticos via WhatsApp
- Dashboard de desempenho e indicadores de manutenção
